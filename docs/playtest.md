# เช็กลิสต์ลองเล่น — มอดภาษาไทย

เปิดเกม (ภาษาไทย) → เข้าเซิร์ฟหรือ world ในเครื่อง · เจอข้อความแปลก ๆ กด **F5** (เกมถ่ายภาพเก็บใน `%APPDATA%\Necesse\screenshots\`) แล้วบอกว่าอยู่หน้าไหน

- [ ] เมนูหลัก / ตั้งค่า (ทุกแท็บ) / สร้างตัวละคร — อ่านออก สระ-วรรณยุกต์ครบ ไม่ล้นปุ่ม
- [ ] คลังของ + tooltip ไอเทม (อาวุธ ชุดเกราะ trinket วัสดุ) — ชื่อมี "(English)" ต่อท้าย
- [ ] ไอเทม/มอนสเตอร์ของ Aphorea — เป็นไทย
- [ ] เมนูคราฟต์ (รวม Quick Recipes) — ชื่อยาวไม่ล้นกรอบจนอ่านไม่ได้
- [ ] คุยกับ NPC / ชาวนิคม (บทพูด ความสัมพันธ์) — ภาษาเป็นธรรมชาติ ไม่มีครับ/ค่ะ
- [ ] หน้านิคม (settlement) / ภารกิจ (quests, objectives) / journal
- [ ] ข้อความตาย / แจ้งเตือน — ชื่อที่แทนค่า (<name>, <item>) ถูกที่
- [ ] แชตพิมพ์ไทย — อ่านได้ (อาจซ้อนสระไม่สวยบางคำ: ข้อจำกัดที่รู้แล้ว)
- [ ] เปลี่ยนภาษาเป็น English → ทุกอย่างเป็นอังกฤษปกติ
