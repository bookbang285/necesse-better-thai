# คู่มือสไตล์การแปลภาษาไทย — Necesse

ทุกคน (รวม agent) ที่แปลหรือแก้คำแปลใน `data/` ต้องอ่านไฟล์นี้และ `data/glossary.json` ก่อน

## 1. เป้าหมาย

- อ่านแล้ว **ลื่นเหมือนเกมที่ทำมาเป็นภาษาไทย** ไม่ใช่แปลคำต่อคำ
- **สั้นพอสำหรับ UI** — ปุ่ม/หัวข้อ/ชื่อไอเทมต้องไม่ยาวกว่าอังกฤษมาก (ชุดตรวจเตือนเมื่อยาวเกิน 2 เท่าในหมวด `ui`)
- **สม่ำเสมอ** — ศัพท์เดียวกันแปลเหมือนกันทั้งเกม ยึด `data/glossary.json` (แถว `approved: true`) เป็นหลัก

## 2. ชื่อเฉพาะ vs คำทั่วไป

| ประเภท | ทำอย่างไร | ตัวอย่าง |
|---|---|---|
| คำทั่วไป/บรรยายได้ | แปลความ | Coin Pouch → ถุงใส่เหรียญ · Demonic Boots → รองเท้าปีศาจ · Crone → ยายเฒ่า |
| ชื่อเฉพาะที่ตั้งขึ้น (บอส, เผ่า, วัสดุแฟนตาซี) | ทับศัพท์ | Runebound → รูนเบานด์ · Spiderkin → สไปเดอร์กิน · Mycelium → ไมซีเลียม |
| ชื่อผสม | ส่วนที่แปลได้แปล ส่วนชื่อเฉพาะทับศัพท์ | Mycelium Greatbow → ธนูใหญ่ไมซีเลียม · Runebound Skull Helmet → หมวกกระดูกรูนเบานด์ |

ลำดับคำตามไทย: คำหลักขึ้นก่อน (ดาบเหล็ก ไม่ใช่ เหล็กดาบ)

## 3. การทับศัพท์

- ตามหลักราชบัณฑิตยสภาเป็นพื้นฐาน **แต่ใช้คำที่คนเล่นเกมไทยคุ้น** เมื่อชัดเจนกว่า — คำเหล่านี้ใช้ตามคลังศัพท์: ไอเทม, เลเวล, บอส, มานา, สกิล, บัฟ, ดีบัฟ, คริติคอล
- ไม่ใส่วรรณยุกต์ในคำทับศัพท์ถ้าไม่จำเป็น: **อัปเดต** (ไม่ใช่ อัพเดท), **อัปเกรด**, **เซ็ต**, **ล็อก**
- ทับศัพท์ให้อ่านออกเสียงใกล้ต้นฉบับ ไม่ต้องเก็บตัวการันต์ทุกตัวถ้าอ่านยาก

## 4. ห้ามแตะ (ชุดตรวจจะจับเป็น error)

- `<ตัวแปร>` เช่น `<name>` `<item>` `<settlername>` `<count>` — **ห้ามแปล ห้ามลบ ห้ามเปลี่ยนชื่อ** ย้ายตำแหน่งได้ตามไวยากรณ์ไทย
- `[input=...]` `[item=...]` `[mob=...]` — ไอคอน ห้ามแก้
- `§` ตามด้วย 1 ตัวอักษร/ตัวเลข หรือ `§#hex6` — โค้ดสี ต้องครบ ย้ายให้ครอบคำไทยที่ตรงกันได้
- `:heart:` — ไอคอน ต้องคงไว้
- `\n` (สองตัวอักษร `\` `n`) = ขึ้นบรรทัด — จำนวนควรเท่าต้นฉบับ (ต่างได้ถ้าจำเป็น ใส่เหตุผลใน `note`)
- **ห้ามใส่ขึ้นบรรทัดจริง / zero-width space / ช่องว่างหัวท้าย**

## 5. บทพูด NPC (`romance`, `personalities`, `mobmsg`)

- **ภาษากลาง ไม่มีคำตามเพศ**: ห้าม ครับ ค่ะ คะ ผม ดิฉัน หนู (ชุดตรวจเตือน) — ใช้ "ฉัน" / "เรา" หรือละสรรพนาม
- ลงท้ายให้มีชีวิตได้ด้วย นะ / เลย / สิ / ล่ะ / น่ะ / จ้ะ(เลี่ยง — ฟังเพศหญิง)
- เรียกผู้เล่นว่า **"คุณ"** หรือละไว้ — **ห้าม "นาย" / "เธอ" / "แก"** (ทางการเดิมใช้ "นาย" หลายที่ → แก้เป็น `fixed`)
- NPC ที่เป็นมิตรใช้ **คุณ / ฉัน** · NPC ฝ่ายศัตรู (บอส, โจร ฯลฯ) ใช้ **เจ้า / ข้า** ได้ แต่ต้องใช้แบบเดียวกันตลอดทั้งตัวละครนั้น
- น้ำเสียงตามอารมณ์ต้นฉบับ: โกรธ → ห้วน, ดีใจ → มีคำอุทาน, จีบ → อบอุ่น
- ไม่เว้นวรรคก่อน `?` `!` (ทางการเดิมมี "ทำไปทำไม ?" → แก้เป็น "ทำไปทำไม?")

## 6. UI

- ปุ่มใช้คำกริยาสั้น ๆ: บันทึก, ยกเลิก, ยืนยัน, กลับ, ออก
- หัวข้อ/ป้ายกำกับใช้คำนาม ไม่ต้องมี "การ" นำหน้าถ้าไม่จำเป็น (ตั้งค่าเสียง ไม่ใช่ การตั้งค่าเสียง)
- ตัวเลขใช้เลขอารบิก · หน่วยเวลา วินาที/นาที · เปอร์เซ็นต์ใช้ `%` ติดตัวเลข
- "OK" → ตกลง · "Yes/No" → ใช่/ไม่ · "Back" → กลับ

## 7. สถานะของแถว

| status | ใช้เมื่อ | th |
|---|---|---|
| `kept` | คำแปลทางการดีแล้ว | คัดลอก `official` ตรง ๆ |
| `fixed` | แก้คำแปลทางการ (ผิด/ไม่ตรงคลังศัพท์/แข็ง/ใช้ "นาย") | ใหม่ + `note` เหตุผลสั้น ๆ เช่น "สะกด", "ศัพท์ตามคลัง", "ภาษากลาง" |
| `new` | ทางการว่าง (เดิมขาด) | แปลใหม่ |
| `same` | ตั้งใจใช้ตามอังกฤษ (ชื่อแบรนด์, ชื่อคนใน credits, ตัวย่อ) | = `en` |

ห้ามเหลือ `todo` · ห้ามแก้ `key` `en` `official`

**ห้ามใส่ชื่ออังกฤษในวงเล็บเอง** — ตอน build ระบบเติม " (English)" ให้ชื่อในหมวด `item` และ `mob` อัตโนมัติ (ไว้ให้ผู้เล่นค้นในเน็ต) · ถ้า official มีวงเล็บอังกฤษอยู่แล้วให้ตัดออก (`fixed`)

## 8. เว้นวรรค

- เว้นวรรคระหว่างประโยค/วลี ตามปกติไทย · ไม่เว้นระหว่างคำ
- เว้นวรรครอบตัวแปรตัวเลขเมื่ออ่านง่ายขึ้น: `ได้รับ <count> เหรียญ`
- ชื่อที่เป็นตัวแปรติดคำไทยได้ถ้าเป็นกรรม: `ให้<item>แก่<settlername>` → ควรเว้น: `ให้ <item> แก่ <settlername>`
